# Lulú y la huerta mágica

Videojuego educativo infantil construido con HTML5, CSS3, JavaScript y Canvas 2D. No requiere instalaciones, servidores, APIs ni dependencias externas.

## Cómo jugar
1. Abre `index.html` en un navegador moderno.
2. Pulsa **Jugar aventura**.
3. Sigue las instrucciones de Lulú y toca los dibujos para completar las cinco misiones.
4. Usa **Pausa** para detener la aventura.

Funciona con mouse y pantallas táctiles.

## Publicar en Vercel
1. Importa este repositorio desde Vercel.
2. Framework Preset: **Other**.
3. Build Command: vacío.
4. Output Directory: `.`.
5. Pulsa Deploy.

## Archivos
- `index.html`: estructura de la página.
- `style.css`: diseño y colores.
- `script.js`: escenas, misiones, interacciones y animaciones.

## Personaje
Lulú está dibujada en Canvas como una lombriz amarilla, larga y sinuosa, con rayas negras, ojos grandes y corona lila, tomando la portada compartida como referencia visual.
